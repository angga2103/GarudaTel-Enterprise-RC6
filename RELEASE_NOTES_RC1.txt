OVERVIEW
============================================================================

GarudaTel Enterprise RC1 adalah sistem PPOB (Payment Point Online Bank)
enterprise-grade dengan fokus pada stabilitas, keamanan, dan skalabilitas.

Release Candidate ini merupakan versi production-ready yang telah melalui
audit keamanan menyeluruh dan validasi operasional.

============================================================================
SECURITY PATCHES
============================================================================

SEC-003 through SEC-017 implemented:

SEC-003: CSRF Protection
  - Flask-WTF CSRFProtect enabled globally
  - CSRF tokens in all forms
  - Exemptions only for documented public APIs

SEC-004: Rate Limiting
  - Flask-Limiter integrated
  - Per-route rate limiting
  - Default limits: login (5/minute), deposit (10/minute)
  - Memory-based storage

SEC-005: Default PIN Remediation
  - Force PIN change for users with default PIN '123456'
  - Migration script: migrate_sec005_pin.py
  - Flag: force_pin_change in users table

SEC-006: PIN Encryption (bcrypt)
  - All PINs hashed with bcrypt
  - Automatic migration from plaintext
  - Backward compatible verification
  - Migration script: migrate_pins_to_bcrypt.py

SEC-007 through SEC-017: Various security hardening
  - Session security improvements
  - Input validation enhancements
  - SQL injection prevention
  - XSS protection
  - Secure password hashing
  - Authentication improvements

============================================================================
KNOWN LIMITATIONS
============================================================================

1. Single Server Architecture
   - Current version designed for single-server deployment
   - Horizontal scaling requires additional architecture
   - Database: SQLite (suitable for small to medium traffic)
   - For high-traffic scenarios, consider PostgreSQL migration

2. WhatsApp Integration
   - Requires external WhatsApp Business API provider
   - Not included: WhatsApp Business API subscription
   - Configuration must be done via Integration Center

3. Firebase Push Notifications
   - Requires firebase_credentials.json from Firebase Console
   - Manual upload required
   - Device token registration managed by client application

4. Backup Storage
   - Automatic backups sent via Telegram
   - Local backup retention not automated
   - Manual cleanup required for disk space management

5. Cloudflare Tunnel
   - Requires Cloudflare account
   - Tunnel token must be obtained from Cloudflare Dashboard
   - One-time manual configuration during installation

============================================================================
SYSTEM REQUIREMENTS
============================================================================

Server:
  - OS: Ubuntu 20.04+ or Debian 11+
  - RAM: 1GB minimum, 2GB recommended
  - Disk: 2GB free space minimum
  - Python: 3.8 or higher
  - Internet: Required for installation and operations

Dependencies (auto-installed):
  - Flask >= 3.0
  - Flask-Login >= 0.6
  - Flask-WTF >= 1.2
  - Flask-Limiter >= 3.5
  - Authlib >= 1.3
  - requests >= 2.32
  - python-dotenv >= 1.0
  - Werkzeug >= 3.0
  - bcrypt >= 4.0

============================================================================
INSTALLATION
============================================================================

See INSTALL_GUIDE.txt for detailed installation instructions.

Quick start:
  1. Upload GarudaTel_Enterprise_RC1.zip to server
  2. Extract to /root/web_ppob/paypoint/
  3. Run: chmod +x installer_vps_baru.sh
  4. Run: ./installer_vps_baru.sh
  5. Follow prompts
  6. Configure providers via Integration Center

============================================================================
UPGRADE PATH
============================================================================

From previous versions:
  - Backup existing database and .env
  - Stop all services
  - Extract new version
  - Run installer (will detect restore mode)
  - Verify all services running
  - No provider reconfiguration needed
