Fix: Cloudflare Tunnel Token validation dan status checker

ROOT CAUSE:

dengan format header.payload.signature (3 parts separated by dots).

FAKTANYA: Cloudflare Tunnel Token adalah base64-encoded JSON single
string tanpa dots. Format: {"a":"account","t":"tunnel","s":"secret"}
