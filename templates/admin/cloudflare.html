Setup Wizard

Ikuti langkah-langkah berikut untuk konfigurasi Cloudflare Tunnel

1
Login ke Cloudflare Zero Trust Dashboard
Buka one.dash.cloudflare.com
2
Create Tunnel
Pilih "Networks" → "Tunnels" → "Create a tunnel"
3
Copy Tunnel Token
Setelah tunnel dibuat, copy token yang dimulai dengan "eyJh..."
4
Paste ke GarudaTel
Paste token di field "Tunnel Token" di atas
5
Klik Save
Konfigurasi akan tersimpan di sistem
6
Klik Test Connection
Verifikasi bahwa konfigurasi sudah benar
⚠️ Catatan Penting
Panel ini hanya untuk menyimpan konfigurasi. Install dan restart tunnel dilakukan secara manual atau via task automation terpisah.
